☁️ Синхронизация с Яндекс.Диском

Данные синхронизируются в файл sklad_data.json в корне вашего Яндекс.Диска. Используется OAuth 2.0 (PKCE) + REST API.

⏳ Статус: не подключено

⚙️ Настройки подключения (один раз)

1. Зарегистрируйте приложение на oauth.yandex.ru
2. Платформа: Веб-сервисы
3. Redirect URI: адрес этой страницы (например, http://localhost:5500/uchet.html)
4. Доступы: Яндекс.Диск REST API → cloud_api:disk.read, cloud_api:disk.write
5. Скопируйте Client ID и вставьте ниже

🔐 Авторизация

Если автоматическая авторизация не работает (например, файл открыт напрямую), получите токен вручную:

  1. Нажмите кнопку выше «Авторизоваться через Яндекс»
  2. После авторизации скопируйте токен из адресной строки (параметр access_token=...)
  3. Вставьте его в поле ниже

🔄 Синхронизация данных

Файл: /sklad_data.json в корне Яндекс.Диска

📋 Инструкция по настройке

1
Зарегистрируйте приложение на oauth.yandex.ru
2
Укажите Redirect URI — адрес, по которому открыта эта страница
3
Включите доступы: cloud_api:disk.read и cloud_api:disk.write
4
Скопируйте Client ID и вставьте в настройки выше
5
Нажмите «Авторизоваться через Яндекс» и разрешите доступ
6
Используйте кнопки загрузки/скачивания для синхронизации
